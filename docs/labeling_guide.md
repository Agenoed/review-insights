# Правила розмітки

Розмічаю тільки по тексту, зірки не дивлюсь.

## sentiment

- `pos` - хвалить, задоволений, все працює ("супер", "зручно", "дякую, все швидко")
- `neg` - скарга, баг, щось не працює, злість. Сарказм теж сюди ("дякую, що знову все впало")
- `neu` - питання, пропозиція без емоцій ("додайте темну тему"), просто факт
- якщо в одному відгуку і похвала, і скарга - ставлю те, чого більше. Якщо порівну - `neu`
- `skip` - спам, незрозумілий набір символів, відгук взагалі не про застосунок
- питання ставлю `neu` тільки якщо людина реально щось питає. Якщо питання вказує на проблему ("Де українська мова?", "Чому не приходить код?") - це `neg`
- "норм", "нормально", "нормальне" - `pos`
- похвала + побажання чи пропозиція без скарги - `neu`
- якщо щось не працює або баг, навіть написано ввічливо - `neg`
- питання "як відновити", "як зробити" без скарги - `neu`

## lang

- `uk`, `ru`, `en` - ставлю мову, якою написана більша частина тексту
- окремі слова з іншої мови (русизми, англійські терміни, назви брендів) мову не міняють
- `other` - інша мова (польська і т.д.)
- `unclear` - не зрозуміти, яка мова: "ок", "супер", "топ"
- транслітерацію визначаю за мовою, а не за алфавітом ("spasibo" - ru)
- суржик окремо не виділяю (коментар керівника), змішаний текст відношу до мови, якої в ньому більше

Розмічаю підряд зверху вниз, без пропусків, щоб вибірка лишалась випадковою.
